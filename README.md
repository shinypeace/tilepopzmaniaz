# Wonder Match

Локальный запуск: Node.js 20.11 или новее, затем `npm start`.
Игра открывается по адресу http://127.0.0.1:4173. Установка npm-зависимостей не нужна.

Проверки: `npm test`. Прогон уровней: `npm run balance -- 2 500`.
Изолированный стенд анимаций: http://127.0.0.1:4173/tests/visual.html.
Стенд не читает и не изменяет сохранения игрока.

Текущий этап — восстановление исходного оформления игрового экрана и проверка механик без пропеллера. Кампания содержит 500 конфигураций; её баланс, карта и остальные вкладки ещё требуют доработки. Это не обозначение готовности к релизу.

- `src/` — игровая модель, уровни, интерфейс, анимации и сохранения.
- `styles/` — стили; `original-style.css` возвращает исходное оформление.
- `assets/source/` — неизменённые исходные изображения.
- `assets/generated/` — дополнительные растровые атласы инструментов и интерфейса.
- `assets/audio/` — звуки и музыка.
- `archive/original.html` — сохранённый исходный HTML до переработки.
- `tests/` — проверки модели, размеров поля и стенд анимаций.
- `docs/` — результаты проверки и сведения об ассетах.

Подробности: [состояние этапа](docs/restoration.md), [источники ассетов](docs/assets.md).
